# Покадрово

Русскоязычный видеоредактор: веб-приложение и самостоятельное нативное приложение для Android.

## Что находится в репозитории

| Путь | Содержимое |
| --- | --- |
| `app/`, `components/`, `lib/` | Веб-редактор, аккаунты, админ-панель, серверные AI-маршруты |
| `android/` | Нативное Android-приложение на Java и Android Media3 |
| `public/downloads/Pokadrovo-2.0.apk` | Подписанная тестовая Android-сборка 2.0 |
| `android/README.md` | Возможности, ограничения и сборка Android |
| `tests/`, `android/tests/` | Проверки логики и безопасности |

## Android

[Скачать APK 2.0](https://github.com/krest0208/pokadrovo/raw/refs/heads/main/public/downloads/Pokadrovo-2.0.apk) · Android 8.0 и новее.

В приложении реализованы локальные проекты, предпросмотр, таймлайн, обрезка и разделение клипов, скорость, настройки звука, изображения и текст поверх видео, импорт SRT, темы и экспорт MP4. Это нативный редактор без WebView.

**Статус: тестовая версия.** Сборка и подпись проверены, выполнено 809 проверок логики таймлайна и субтитров. Запуск и экспорт на физическом устройстве ещё требуют проверки. ИИ, регистрация, социальный вход, админка и облачная синхронизация в Android 2.0 не подключены.

Инструкция по сборке и полный список ограничений: [android/README.md](android/README.md). Закрытый ключ подписи и пароль в репозиторий не включены. Для выпуска обновления с той же подписью необходим приватный ключ владельца.

## Веб-приложение

Интерфейс на React/TypeScript, серверные маршруты на базе Next/Vinext, размещение в Sites / Cloudflare Workers, база D1. Редактор поддерживает локальные медиа и проекты, ручной монтаж, субтитры и экспорт. Серверные AI-функции, почтовый вход, Google/VK и админка требуют настройки соответствующих сервисов и секретов.

Текущий сайт: https://framecut-studio.kh-ng-gian-l-3883.chatgpt.site — доступ определяется настройками хостинга, публичность этого репозитория его не меняет.

### Подготовка разработки

Требуется Node.js 22.13+ и pnpm. После установки зависимостей команды определяются `package.json`:

```bash
pnpm install --frozen-lockfile
pnpm dev
pnpm build
```

Проект сохраняет интеграцию Sites. Полноценная работа серверных маршрутов требует настроенного окружения Cloudflare, D1 и секретов. На другом хостинге понадобятся адаптация сборки и авторизации: текущие заголовки владельца доверяются шлюзу Sites, нельзя принимать такие заголовки напрямую от посетителей.

## Секреты и данные

В репозитории нет настоящих API-ключей, `.env`, паролей подписи, базы пользователей и выгрузок заказов. Значения в тестах — синтетические примеры. Рабочие секреты задаются на сервере; они не должны попадать в клиентский код или APK.

Оплаты и подписки не подключены. Список пользователей и статистика сайта хранятся в серверной базе, а не в исходниках. Наличие маршрутов в коде не означает, что все провайдеры уже настроены.
